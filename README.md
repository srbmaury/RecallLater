# RecallLater

A private, local-first inbox that turns anything you share from your phone into something you can act on later. See [plan.md](plan.md) for the product plan.

**Share it now. Deal with it when it matters.**

## What V1 does

1. **Share** a screenshot, photo, PDF, link or text to RecallLater from any app (iOS Share Extension / Android share intents via `expo-sharing`).
2. **Read it on-device**: Apple Vision / ML Kit OCR, PDF text, QR codes (`modules/recall-native`).
3. **Understand it** with deterministic parsing, no AI: dates, amounts, PNR / flight / train numbers, order IDs, coupons, return windows, then classify as bill, task, event, travel, receipt, purchase or generic (`src/lib/parse`).
4. **Review** the title, type and suggested reminder, then save to SQLite. Files are copied into app-private storage.
5. **Resurface** it with local notifications, including *remind until done*, on the Today screen.

Nothing leaves the device. There is no account, no backend, no analytics, and Android auto-backup is disabled.

## Project layout

```text
src/app/                 Expo Router screens
  (tabs)/                Today, Inbox, Collections, Search, Settings
  share.tsx              Review screen shown after sharing into the app
  item/[id].tsx          Item detail
  +native-intent.ts      Routes expo-sharing links to /share
src/lib/
  parse/                 Deterministic understanding (pure TS, unit tested)
  db/                    SQLite schema/migrations (FTS5 search) and queries
  intake.ts              Share payloads → private files + extracted text
  reminders.ts           Local notifications, remind-until-done, actions
  calendar.ts            Pre-filled OS "new event" sheet
modules/recall-native/   Local Expo module: Vision + PDFKit (iOS), ML Kit + PdfRenderer (Android)
```

## Develop

Requires Node 20+, JDK 17–21 for Android, and Xcode 16+ for iOS.

```bash
npm install
npm test            # parser + search unit tests
npm run typecheck
npm run lint

npm run android     # builds a development client and installs it on a device/emulator
npm run ios         # needs Xcode; or build in the cloud: npx eas-cli@latest build --profile development --platform ios
```

This app uses native code (share extension, OCR), so it **does not run in Expo Go**. `ios/` and `android/` are generated by `npx expo prebuild` and are not committed. Configure native behavior in `app.json` or the local module instead.

To try the share flow on Android, open Chrome, Photos or Files, tap **Share** and pick **RecallLater**. You can also run:

```bash
adb shell am start -a android.intent.action.SEND -t text/plain \
  --es android.intent.extra.TEXT "'Can you send me the updated deck before we speak on Friday?'" \
  com.srbmaury.recalllater
```

## Known limitations (V1)

- On iOS the share extension hands off to the main app, which `expo-sharing` notes is not officially supported by Apple.
- Notification actions (**Done** / **Later**) open the app so the change is applied reliably.
- "Remind until done" keeps 3 daily nudges queued per item and tops them up whenever the app opens.
- PDFs: the first 5 pages are read. On Android every page is OCR'd because `PdfRenderer` exposes no text layer.
- Parsing is tuned for India first: ₹/Rs, day-first dates, Indian carriers and utilities.
